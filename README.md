# RAYANE COACHING

Site vitrine du coach en ligne Rayane ([@rayane_fit](https://www.instagram.com/rayane_fit/)) :
formules et prix, inscription envoyée sur son WhatsApp, en arabe et en français.

**Site en ligne : https://rayane-coaching.pages.dev/**

- Le code du site est dans [`front/`](front/), avec son mode d'emploi : [front/README.md](front/README.md).
- Chaque `git push` sur `main` met le site à jour sur Cloudflare Pages
  (réglages : [front/README.md → Mise en ligne](front/README.md#mise-en-ligne)).
